# 页面需求与样式调整范围

本说明供后续视觉设计参考。视觉方案可以调整配色、字体、留白、卡片、图标与控件样式；业务字段、数据来源、状态反馈和手机可用性需要保留。首版样式集中在 `src/styles.css`，关键颜色与圆角使用 CSS 变量。

## 共同要求

移动端优先，至少适配 375px 宽度；电脑浏览器可舒适演示。导航包含档案、选专业、对比、候选和助手，品牌链接回首页。颜色不能成为风险区分的唯一方式。表单有可关联标签、键盘焦点和错误说明；图表提供文本数据。空状态、加载、错误和服务回退必须有设计，不能只给正常状态。

## 页面内容

| 页面         | 主要内容                                                                   | 关键操作与状态                                                               |
| ------------ | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 首页         | 产品目的、三步流程、真实与模拟数据边界、官方来源                           | 开始填写、先看示例、继续已有档案                                             |
| 档案与偏好   | 上海2026场景、分数、位次区间、三门选科、意向专业、九项权重                 | 前五项默认显示；提交按钮上方有进阶展开，显示后四项和费用预算；校验失败可定位 |
| 推荐结果     | 档案摘要、搜索、风险筛选、维度排序、学校专业卡片                           | 加载、空结果、API回退；每次展示20项，可加载更多；收藏与最多3项对比           |
| 学校专业详情 | 学校与示例专业组、匹配分、风险解释、九项贡献、八维与六维图、就业和三年趋势 | 查看计算、收藏、加入对比、带着问题进入助手；条件不符时不显示个性化分数       |
| 对比         | 2—3项学校专业，统一比较城市、条件、费用、就业和各维度                      | 移除、加入候选；手机上表格可横向滚动；不足2项有提示                          |
| 候选清单     | 已收藏项、当前匹配状态、排序                                               | 上移下移、移除、加入对比、导出；不是正式志愿表                               |
| 问答助手     | 当前档案、六类建议问题、消息与来源                                         | 发送中、失败、限流、基础/模型/回退标识；长文本不溢出                         |

## 偏好字段顺序

默认五项依次为地域偏好、城市类别、学校综合排名、专业排名、专业师资力量。进阶四项依次为就业质量、考公考编友好度、创新能力、学费与生活成本。收起后仍参与计算；展开按钮摘要显示后四项合计权重。调整一项时其他项按比例改变，合计固定为100%。

## 不应因换样式丢失的内容

模拟数据标识、专业组选科要求、匹配与风险的区分、来源链接、错误反馈、超出对比数量的提示，以及模型实际运行模式。避免为了界面整齐而隐藏缺失数据，也不为装饰图表补写真实数据。
