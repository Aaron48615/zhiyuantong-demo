# 页面需求与样式调整范围

本说明记录当前页面的内容、交互和样式约束，供后续设计与开发使用。更新日期：2026-10-08。视觉方案可以调整配色、字体、留白、卡片、图标与控件样式；业务字段、计算规则、状态反馈和手机可用性需要保留。样式集中在 `src/styles.css`，关键颜色与圆角使用 CSS 变量。

## 公共布局与控件

页头品牌只显示“智愿通”，链接回首页，不附带独立“智”字图标或场景副标题。导航包含档案、选专业、对比、候选和问助手；对比和候选存在已选内容时显示数量。浏览器页面标题统一为“智愿通”。页脚使用占位版权信息 `© 2026 智愿通. All rights reserved.`。

界面使用墨青主色、蓝色选中状态和灰白背景，正文区最大宽度为 960px。普通按钮、预设按钮、专业及地区选择项、选科项、风险筛选和导航采用 6px 圆角；输入框采用 10px 圆角，主要面板采用 14px 圆角。开关、数量徽标等特殊控件保留各自形状。导航选中状态通过背景和字重表达，键盘焦点描边为 1px。下拉框使用自定义箭头，距右边缘 14px，并为文字预留右侧空间。

档案页的滑动条纵向排列；推荐卡片在桌面上显示两列，700px 及以下改为单列。普通主要操作至少高 44px；筛选区的对比管理按钮为 36px，移除按钮为 32px，进阶开关为 26px 高。后续设计可以扩大紧凑控件的点击区域，不能把所有现有控件描述为均已满足 44px。

档案页提交区贴近视口底部，推荐页筛选区吸顶，对比管理直接放在筛选区内。手机布局下，档案中的数字输入或选择框获得焦点时，提交区恢复普通文档流；筛选区中的输入或选择框获得焦点时，筛选区恢复普通文档流。700px 及以下且视口高度不超过 550px 时，两者均恢复普通布局。手机实机软键盘行为仍需单独验收。

## 共同要求

移动端至少适配 375px 宽度，电脑浏览器可舒适演示。表单有可关联标签、键盘焦点和错误说明；颜色不能成为风险区分的唯一方式，图表提供文本数据。空状态、加载、错误、重试和服务回退应有对应反馈。这里的尺寸与交互要求是后续验收标准，不代表所有设备均已完成测试。

档案编辑使用独立草稿。调整滑动条、切换进阶偏好或使用预设后，可以立即查看比例预览；只有通过校验并保存，才更新已保存档案和推荐结果。

## 档案输入与选项范围

档案页说明只保留“先确认报考条件，再调整选择的侧重点。”。首次填写时总分输入框为空；已有档案仍显示已保存分数。点击“使用示例档案”才主动填入示例分数和其他示例配置，提交后生效。

选考科目必须选择三门不同科目。意向专业可多选，不选表示不限；选中后按专业筛选推荐。想去的省市用于偏好评分，不强制排除其他地区。

当前选项来自 `src/data/generate.ts` 的本地数据：意向专业为计算机科学与技术、软件工程、自动化、电子信息工程、工商管理、国际经济与贸易；地区为上海、江苏、浙江、安徽、福建、湖北、湖南。前后端使用同一套50所学校、300个学校专业组合的固定示例数据，当前没有包含更多选项的独立数据库。

## 独立重视程度与进阶开关

基础五项顺序为地域偏好、城市类别、学校综合排名、专业排名、专业师资力量。进阶四项顺序为就业质量、考公考编友好度、创新能力、学费与生活成本。每项滑动条取0—10的整数，共11个位置；0表示不参与，10表示非常重视。滑动一项只改变该项的档位，其他滑动条保持原值。档位表示相对重视程度，不直接表示百分比。

默认各项档位均为5，进阶开关关闭，只有基础五项参与计算，因此默认各占20%。进阶开关同时控制四项设置的显示与计算参与：关闭后四项占比为0，基础五项重新构成100%；开启后九项共同换算比例。关闭时保留四项档位和预算输入，再次开启时恢复。此处没有“只收起界面、仍参与计算”的独立折叠状态。

预算只在进阶偏好已启用且费用档位大于0时参与费用评分，并校验5000—200000元范围；不参与时不因预算输入阻止保存。

计算规则如下，分母只包含当前启用的项目：

```text
某项计算占比 = 该项档位 ÷ 所有启用项的档位之和 × 100%
偏好匹配分 = 各项评分 × 对应计算占比的小数形式，再求和
未启用项的计算占比 = 0
```

页面实时显示各项计算占比及“保存后使用的比例”预览。保存原始档位和进阶开关状态；前端与本地API使用同一归一化函数计算推荐，不在拖动时覆盖输入档位。计算保留未取整比例，页面显示一位小数，显示值相加可能出现99.9%或100.1%的舍入差异。当前启用项全部为0时不能保存，提示至少将一项已启用的重视程度设为1或以上；关闭状态下保留的进阶档位不计入该校验。

| 预设 | 档位设置 | 进阶开关 |
| --- | --- | --- |
| 均衡考虑 | 九项均为5 | 关闭 |
| 更重视学校 | 学校为10，其余为5 | 关闭 |
| 更重视就业 | 就业为10，其余为5 | 开启 |
| 更重视费用 | 费用为10，其余为5 | 开启 |

本地持久化保存 `preferences`、`advancedEnabled`，并使用 `preferenceVersion: 2` 标识新规则。读取旧版档案时，将旧权重直接初始化为新默认档位和关闭的进阶开关，保留其他档案字段、收藏和对比记录，不按旧百分比反推档位。

## 推荐分页、推荐理由与对比管理

推荐页每页展示20张现有学校专业卡片，不按学校合并去重。分页器提供上一页、下一页、页码和省略号，首尾页禁用对应翻页按钮；最后一页可少于20张，空结果不显示分页器。搜索、风险筛选或排序变化后回到第一页；点击页码后回到筛选区附近。翻页替换当前结果，不继续累加卡片。

推荐卡片的理由使用可直接理解的描述，例如“考公考编友好度高”或“就业质量较好”，不再显示“评分×权重≈贡献分”的公式。理由应与该项实际评分及用户偏好相符；未设置地区或城市偏好时，不生成对应的虚假优势理由。卡片仍保留匹配分，详细评分和贡献计算可在详情页查看。

已选对比放在吸顶筛选区内，采用紧凑的数量、管理按钮和查看对比链接。展开管理后，以“学校·专业”的紧凑标签显示已选项，每项提供移除按钮；即使对应卡片不在当前分页或被筛选隐藏，也可直接移除。最多选择3项。卡片和对比页原有移除入口继续可用，不再使用固定在视口底部的深色浮动对比栏。

推荐页已删除整块模拟数据及录取风险提示，页脚已替换为占位版权信息，后续样式调整不应恢复这两处旧文案。首页数据说明、风险标识、详情来源、助手运行模式和导出中的相关信息按各自实际内容保留；API不可用时仍显示服务回退提示。

## 后续调整应保留的行为

保留专业组选科要求、匹配分与风险分档的区分、来源链接、错误反馈、全零校验、对比数量限制，以及助手实际运行模式。缺失数据按现有状态展示，不为装饰图表补写真实数据。偏好输入继续保持独立，进阶关闭后不参与计算，分页继续按20张卡片切换。
