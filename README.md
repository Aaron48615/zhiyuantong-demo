# 智愿通

面向上海普通本科考生的志愿选择原型。通过选科过滤、九项偏好加权、学校与专业对比，帮助考生整理候选清单。前端使用 Vue 3、TypeScript、Vue Router、Pinia、Axios 与 ECharts，附一个本机运行的 Node.js 接口示例。

## 运行

需要 Node.js 22.12 或以上版本，建议使用 Node.js 24。

```bash
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173`。该命令同时启动前端和端口 3001 的本机 API。首次运行不需要账号、数据库或模型密钥；助手使用基础规则问答。

```bash
npm test                 # 推荐、数据与基础问答测试
npm run build           # 类型检查与生产构建
npm run preview         # 预览构建，API 需另开 npm run dev:api
npm run data:generate   # 一键生成 var/demo-data.json
```

生产构建支持纯静态托管，使用 Hash 路由，不需要服务端路由重写。静态环境没有 API 时，推荐回退到同一套本地计算，问答明确显示基础问答回退。不要把本地代理直接暴露为公开的付费模型接口。

## 已实现流程

- 档案填写与校验；默认显示前五项偏好，提交按钮上方的进阶设置展开其余四项。
- 九项权重总和固定为 100%；预设方案、手动调整与本机持久化。
- 选科硬过滤、意向专业筛选、偏好评分、模拟冲稳保分档；按八项学校维度和六项专业维度排序。
- 学校与专业详情、雷达图、毕业去向图、三年去向落实率、岗位与费用信息。
- 2—3 项横向对比，候选收藏、排序、JSON 导出。
- 六类基础问答、页面内上下文；可选 DeepSeek 数据辅助回答。

## 数据范围

本项目的填报场景固定为上海 2026 年普通本科。真实资料包括上海考试院的公开规则与 2026 年成绩分布，以及可访问的 2023—2025 年专业组投档资料链接。`src/data/score-distribution-2026.json` 的 214 条记录来自官方 PDF，保留来源与发布日期。

`src/data/generate.ts` 使用固定种子生成 50 所学校样本和 300 条专业记录。学校名称和城市用于展示；专业设置、专业组、所有评分、专业历史位次、学费生活费和就业数据均为模拟，**不代表这些学校实际开设的专业或招生情况**。专业组只用于演示上海业务层级。页面、问答和导出文件都保留模拟标识。

专业组投档线不等于组内专业录取线，不能把相同组代码自动视为跨年同一专业集合。高分段公开资料还存在截断。本项目不使用 2026 年最终投档结果预测 2026 年填报，不输出未经验证的精确录取概率。

## 核心计算

资格过滤先于评分：所有要求科目必须包含在考生选科内。地域、城市和费用用于偏好评分，不自动成为排除条件。意向专业为可选硬筛选。

```text
匹配分 = Σ（维度评分 × 用户权重 / 100）
模拟位次比 = 考生位次 / 前三年模拟专业录取位次中位数
位次比 ≤ 0.85：保；≤ 1.05：稳；其余：冲
```

位次越小代表排名越靠前。用户不填写位次时，根据官方同分区间末位进行保守演示；该值不等于真实同分投档位序。分档阈值是原型规则，尚未进行历史效果校准。匹配分只衡量偏好，不与风险分档相乘；具体计算与贡献分可以在详情中展开。

## 可选的 DeepSeek 接入

将 `.env.example` 复制为 `.env`，只在本机填写 `DEEPSEEK_API_KEY`。模型通过 `DEEPSEEK_MODEL` 指定，默认 `deepseek-chat`。修改后重启 API。请求会将当前考生档案、最近最多 12 条消息和查询结果发送给 DeepSeek，按该服务的实际调用计费。

密钥仅在服务端读取，不能使用 `VITE_` 前缀。仓库忽略 `.env`。代理仅监听 `127.0.0.1`，对模型调用设 20 秒超时、每分钟最多 10 次、最多 2 个并发请求。配置密钥前仅能验证基础模式；真实模型的响应质量与费用需要接入后另行验证。
